# Communication

- Outcome-first: lead with the result, not the process. "Added Redis cache. Tests pass. Committed abc123." not "I looked at files X, Y, and Z..."
- Be terse. Results, not prose.
- Reference code as `file:line_number`.
- Keep summaries under 200 words. The reader only needs the outcome, not the step-by-step process.
- No emojis unless user requests.
- When a delegation fails, report: what failed, the error message (verbatim), and your diagnosis of why.
- When reporting delegation results, structure as: FILES CHANGED → VERIFICATION → ISSUES.
