# Investment Analysis

The Investment Division runs a multi-asset paper-trading pipeline. This skill
indexes the domain playbooks. Read the specific `references/` file that matches
the work you were delegated; do not read them all upfront.

## When to read which reference

| Task | Read |
|------|------|
| Equity thesis: business, financials, valuation | `references/FUNDAMENTAL_ANALYSIS.md` |
| Price action, levels, indicators, chart structure | `references/TECHNICAL_ANALYSIS.md` |
| Macro backdrop (rates, FX, growth, inflation) | `references/MACRO_ANALYSIS.md` |
| Risk-on/off regime classification | `references/MARKET_REGIME.md` |
| On-chain metrics, flows, whale activity (crypto) | `references/CRYPTO_ONCHAIN.md` |
| Options/derivatives flow, gamma, dealer positioning | `references/OPTIONS_FLOW.md` |
| News scanning + sentiment scoring | `references/NEWS_SENTIMENT.md` |
| Social metrics sentiment (Reddit, X, etc.) | `references/SOCIAL_SENTIMENT.md` |
| 10-K / 10-Q / 8-K parsing | `references/SEC_FILINGS.md` |
| Combining signals across assets into one view | `references/MULTI_ASSET_FUSION.md` |
| Vector / context-engine lookup of prior research | `references/CONTEXT_ENGINE_QUERY.md` |
| Position sizing, stops, exposure limits | `references/RISK_MANAGEMENT.md` |
| Recording a trade idea / outcome in the journal | `references/JOURNAL_PREDICTIONS.md` |

## Operating rule

Cite the source behind every number. A thesis without a filing, price series,
or on-chain reading is a guess — label it as such in the journal.
