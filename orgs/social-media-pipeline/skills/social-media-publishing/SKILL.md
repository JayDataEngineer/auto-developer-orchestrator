# Social Media Publishing

The Social Media Pipeline turns a brief into researched, drafted, and (on
approval) posted content across Twitter and Telegram. This skill indexes the
pipeline playbooks. Read the `references/` file for the stage you were
delegated.

## When to read which reference

| Task | Read |
|------|------|
| Research what's trending / worth posting on X | `references/TWITTER_RESEARCH.md` |
| Research what's landing on Telegram channels | `references/TELEGRAM_RESEARCH.md` |
| Drafting creative copy (hooks, threads, posts) | `references/CREATIVE_DRAFT.md` |
| Generating images for a post | `references/IMAGE_GEN_WORKFLOW.md` |
| Final presentation + posting the finished content | `references/PRESENT_AND_POST.md` |

## Operating rule

Research before draft, draft before image, image before post. Do not post
content the operator has not approved at the presentation stage.
